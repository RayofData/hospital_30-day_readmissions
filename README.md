# Hospital 30-Day Readmissions

A portfolio data science project exploring hospital readmissions among patients with diabetes.

The project will use the UCI Diabetes 130-US Hospitals dataset to build a binary classification model for predicting whether a patient is readmitted within 30 days.

**Status:** Project setup and initial exploration.

## Dataset

Dataset: [Diabetes 130-US Hospitals for Years 1999–2008](https://archive.ics.uci.edu/dataset/296/diabetes+130-us+hospitals+for+years+1999-2008)
Clore, John, et al. "Diabetes 130-US Hospitals for Years 1999-2008." UCI Machine Learning Repository, 2014, https://doi.org/10.24432/C5230J.
